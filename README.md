# Global Population Report-generating Java App

The Global Population Report-generating app is developed for the assessment of DevOps Course (SET09803) by Group 6, a team formed by students from Edinburgh Napier University.

The project is contributed by the team members equally in designing, implementing, testing, and delivering the system/application as the project outcome.

## Project Information

**Project:** Global Population Report-generating App

**Language used:** Java

**JDK Version:** Temurin 25.0.4

**Build Tool:** Maven

**Database used:** MySQL
